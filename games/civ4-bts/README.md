# Civilization IV: Beyond the Sword

Native port of **Civilization IV: Beyond the Sword**, using GOG 3.19. Fully
playable in single player. Networking is currently unsupported, and work continues
on occasional performance issues. Importing requires the base-game assets and an
additional DLL.

Voice recording is not implemented. Mods that provide their own
`CvGameCoreDLL.dll` will not work automatically; their DLL requires separate
manual handling and translation.

For build instructions and technical notes, see [DEVELOPMENT.md](https://github.com/wraitii/recomp-toolkit/blob/main/games/civ4-bts/DEVELOPMENT.md).
