# Black & White

Native port of **Black & White (2001)**, using the PC release with Fan Patch
1.42. Single-player gameplay is expected to be fully playable; the first island
has been tested, with a full playthrough still pending. Networking is currently
unsupported.

The port ships with increased LOD range by default, keeping distant objects and
terrain detailed for longer. Unlike the original game, resolution can be changed
from the in-game Options menu; changes take effect after restarting.

For build instructions and technical notes, see [DEVELOPMENT.md](https://github.com/wraitii/recomp-toolkit/blob/main/games/black-and-white/DEVELOPMENT.md).
