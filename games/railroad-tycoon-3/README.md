# Railroad Tycoon 3

Native port of **Railroad Tycoon 3 (2003)**, using the GOG release with official
patch 1.05 and no unofficial user patch. Disc editions are unverified. Fully
playable in single player with good performance. Networking is unsupported.

For build instructions and technical notes, see [DEVELOPMENT.md](https://github.com/wraitii/recomp-toolkit/blob/main/games/railroad-tycoon-3/DEVELOPMENT.md).
