# 4x4 Evolution 2

Native port of **4x4 Evolution 2**, using PC version 1.00.139 and its matching
Direct3D renderer DLLs. Fully playable in single player with good performance.
Networking is currently unsupported. A bug is under investigation that may also
occur in the original game in the career garage. The OpenGL renderer is
unsupported.

## Controller setup

Open the installed game's **Configure** app and select **Controller setup**.
On **Overview**, check that your controller responds and choose a starting
preset. Use **Mapping** to assign its controls to gamepad buttons or keyboard
keys; **Identify input** selects the control you move or press.

If an axis drifts or does not reach its full range, use **Calibration**. Choose
**Centered (stick / wheel)** for controls that rest in the middle, or **One-sided
(trigger / pedal)** for controls that rest at one end. Select **Save** to keep
the profile.

For build instructions and technical notes, see [DEVELOPMENT.md](https://github.com/wraitii/recomp-toolkit/blob/main/games/4x4-evo2/DEVELOPMENT.md).
