# Tom Clancy's Ghost Recon (2001)

Native port of **Tom Clancy's Ghost Recon (2001)**, using GOG 1.4. Fully playable
in single player with good performance. Networking is currently unsupported.
Desert Siege and Island Thunder use the same executable with their expansion data.

Ctrl+Option+M releases mouse capture. The port adds an **FXAA** option under the
in-game **Port** options tab; enable it to smooth scene edges. The setting can
also be initialized with `RECOMP_FXAA=1`.

For build instructions and technical notes, see [DEVELOPMENT.md](https://github.com/wraitii/recomp-toolkit/blob/main/games/ghost-recon/DEVELOPMENT.md).
